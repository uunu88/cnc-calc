    [ 전조탭이란? ] 절삭이 아닌 소성변형(전조)으로 나사산을 성형하는 탭. ▶ 명칭 정리 — 모두 같은 공구입니다 · 전조탭 (轉造) : 소성변형으로 만든다는 뜻 · 롤탭 (Roll Tap) : 현장에서 가장 많이 쓰는 이름 · 성형탭 : 한자어 다른 표현 · 플루트리스 탭 : 홈(Flute)이 없다는 특징 강조 · 폼탭 (Form Tap) : 소성변형(Forming) 강조 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ [ 핵심 특징 ] 1. 칩이 발생하지 않음 → 칩 배출 문제 원천 차단 (막힌 구멍에 유리) 2. 기초홀이 절삭탭보다 큼 → 소재가 나사산으로 유동해야 하므로 여유 필요 → 절삭탭 : 드릴 = D − P → 전조탭 : 드릴 = D − P/2 예) M6×1.0 → 절삭 5.0mm / 전조 5.5mm 3. 나사산 강도가 증가 → 냉간가공 경화 효과 (15~30% 강도 상승) 4. 나사산 표면이 매끄러움 → 골밀도 높음, 피로강도 우수 5. 공구 수명이 길다 → 절삭탭 대비 3~10배 (재질에 따라) 6. 절삭 토크가 크다 → 장비 강성 및 홀더 견고함 필요 7. 회전 속도 상향 가능 → 절삭탭 대비 +20~30% (Vc 기준) ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ [ 적합 / 부적합 재질 ] ▶ 적합 (연성 재료) · 알루미늄, 황동, 구리 · 저탄소강, 연강 · 스테인리스 (일부 300계) · 아연 합금 ▶ 부적합 (취성 재료) · 주철 (FC, FCD) · 소결재 · 고경도강 (45 HRC↑) · 마그네슘 합금 (일부) ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ [ 기초홀 (전조탭 기준) ] M3×0.5 → Ø2.75 M4×0.7 → Ø3.65 M5×0.8 → Ø4.60 M6×1.0 → Ø5.50 M8×1.25 → Ø7.40 M10×1.5 → Ø9.25 M12×1.75 → Ø11.10 M16×2.0 → Ø15.00 M20×2.5 → Ø18.75 ※ 제조사별로 ±0.05mm 차이 있을 수 있음 ※ 정밀 나사는 샘플 테스트 후 확정 권장 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ [ G코드 지령 ] 절삭탭과 동일하게 G84 사용. 리지드탭은 M29 필수 (Fanuc 기준).
